## 独立预检入口

运行 `node scripts/serve-regression.mjs`，仅监听 127.0.0.1:4174。普通预览仍在4173，正式页面不加载测试前置脚本。

入口示例：`http://127.0.0.1:4174/MeituanDemo-YSH.github.io/?case=seed-retry&run=your-run-id`。run 可由1–40位字母、数字、下划线、连字符组成，换一个 run 使用新的独立测试记录。

支持 normal、seed-retry、seed-invalid、seed-slow、reset-fails、storage-denied、storage-write-fails、storage-corrupt、schema-unsupported、deadline-race、initialization-race、offline-after-load。每个场景使用独立测试存储前缀，不接触原正式源记录。

offline-after-load 只阻断后续数据 fetch，不能替代设备断网测试；本项目没有 Service Worker，不承诺首次离线可打开。deadline-race 只在发布提交期间推进服务时钟，用于二次校验。initialization-race 在首次慢加载期间模拟已有新快照，刷新恢复该快照。
