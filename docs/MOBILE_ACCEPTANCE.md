## 测试设备与职责

开发负责人安排两台真机或可靠的真机测试服务：一台 iPhone/Safari、一台 Android/Chrome；记录机型、OS、浏览器版本、测试时间、代码提交号。项目目标下限为 iOS 16 / Android 10，若没有对应低版本设备，只能声明已测版本，不承诺全部目标版本均已支持。

桌面 Edge 的尺寸模拟只用于布局回归；不能覆盖 iOS WebKit、软键盘、系统手势和实际移动网络。微信内置浏览器单列为补充项。

## 必测场景

| 编号 | 操作 | 预期结果 | 严重级别 |
| --- | --- | --- | --- |
| M01 | 直接打开正式链接 | 无需注册；显示演示提示与初始任务；不空白 | 阻塞 |
| M02 | 切到各页面并横竖屏旋转 | 无横向溢出、遮挡；滚动和返回可用 | 严重 |
| M03 | iPhone 查看底部导航和详情操作条 | 避开 Home 指示条；末条内容未被盖住 | 严重 |
| M04 | 两端编辑发布表单最后一个字段 | 聚焦字段、错误信息和提交入口可滚动到；键盘收起后布局恢复 | 阻塞 |
| M05 | 字体放大/浏览器缩放到 200% | 文本可读；核心操作仍可完成；不禁止缩放 | 严重 |
| M06 | 点击卡片内按钮、筛选、标签页 | 点击区域足够；不误触卡片导航或重复操作 | 严重 |
| M07 | 非法金额、空白标题、已过截止时间发布 | 明确字段提示，输入保留，无新任务产生 | 严重 |
| M08 | 用 u001 发布，再切 u002 接单 | 两个身份各自看到正确操作；同校区；不能自接 | 阻塞 |
| M09 | u002 开始并提交完成，切回 u001 确认 | 状态依次正确；u002 信用只增加一次 | 阻塞 |
| M10 | 连续点确认、返回后再点、刷新 | 无重复订单、重复信用事件、重复评价 | 阻塞 |
| M11 | 用 u005 接单；接自己的任务；接过期任务 | 分别给出低信用、自接、过期提示；数据不改变 | 严重 |
| M12 | 刷新、关页重开、从详情链接进入 | 恢复本地记录；样例日期不因刷新重置；详情路径不 404 | 严重 |
| M13 | 存储不可用/损坏、种子加载失败 | 无白屏；出现可恢复提示；临时数据不伪称持久化 | 严重 |
| M14 | 重置演示、切换用户 | 先确认重置；还原全部状态和积分；切换身份不清空数据 | 严重 |
| M15 | 过期、取消、争议、无结果列表 | 状态和按钮符合规则；不凭空扣分；能返回大厅 | 严重 |
| M16 | 首次加载慢网；已加载后断网 | 加载有反馈；可重试；已加载的本地操作可用；首次离线不虚称可用 | 严重 |
| M17 | 手机蜂窝网络与未登录浏览器访问 | 无 GitHub 登录要求；HTTPS 正常；资源加载成功 | 阻塞 |
| M18 | 查看信用记录及双方评价 | 统计从数据推导；虚构数据有标记；双向评价互不覆盖 | 严重 |
| M19 | Android 系统返回及 iOS 返回手势 | 按历史返回合理页面；未提交表单有合理保留或提示 | 严重 |
| M20 | 输入含 HTML 标签或超长文字 | 以纯文本显示，无脚本执行，不撑破页面 | 阻塞 |

性能项目目标（需实测，并非当前结果）：首屏压缩资源合计尽量低于 500KB、单张图片低于 150KB、种子低于 100KB；在明确记录的中端 Android/4G 环境中，目标 3 秒内显示可操作内容。任何外部字体/图片依赖都要说明，优先随项目托管资源。
