# 三分钟演示走查

适用版本：v0.7.0-rc.1 候选预览。固定入口：[校园跑腿互助平台](https://shawnyoung-ysh.github.io/MeituanDemo-YSH.github.io/)。

本项目是响应式 H5：同一浏览器内切换虚构身份，展示发布、跑腿、确认、信用与互评；没有真实账号认证、支付或跨设备数据库。候选包已准备，完整手机发布门槛待完成，见 [版本报告](RELEASE_REPORT.md)。

## 演示前准备（不计入三分钟）

1. 用同一设备、同一浏览器、同一网址及一个标签页演示。不要在另一个同源标签页切换身份，否则旧页会要求刷新。
2. 打开“我的”，点击“重置演示”并确认。重置会清除本浏览器的虚构任务、评价与信用变动；需要保留的演示记录先自行留存截图。确认默认身份小周、阿晴初始信用 80。
3. 返回大厅，确认版本、虚构说明和 4 条待接单样例；确认网络可加载种子。演示期间使用“2 小时后”快捷截止，避免手工日期和临界过期。
4. 熟悉“我的”下方的身份切换位置；准备下面的短文本，不填写真实联系方式或取件码。首次说明可以在开场确认。

## 主演示脚本

| 时间 | 页面操作 | 讲解与观察点 |
| --- | --- | --- |
| 00:00–00:15 | 大厅查看类别、取送地点和酬谢；确认首次说明 | “这是同校区的虚构跑腿需求，无需注册即可体验。” |
| 00:15–00:55 | 发布：代取快递；标题“顺路帮取小包裹”；说明“虚构小件包裹，请从北门驿站送到学生公寓公共门厅。”；北门驿站→学生公寓公共门厅；2 小时后；酬谢 3.50；预算留空；发布 | “酬谢与商品预算分开，当前不会支付。发布后进入详情，发布者不能接自己的任务。” |
| 00:55–01:25 | 我的→切阿晴→切换身份；大厅按刚才标题找到新任务→接下任务→确认接单 | “演示身份切换保留任务；接单需要同校区、信用至少 60、任务未截止。” |
| 01:25–01:50 | 开始跑腿→提交交付说明“已送到公共门厅，虚构演示交付完成。”→提交 | “交付后是待确认，此时信用仍为 80，不提前入账。” |
| 01:50–02:20 | 我的→切小周；我的任务→我发布的→新任务→确认完成→确认完成并入账 | “确认后已完成，阿晴信用 80→82；同一任务只入账一次，最高 100 分。” |
| 02:20–02:55 | 详情下方给阿晴 5 星；我的→切阿晴→查看信用明细并点该任务→给小周 4 星 | “双方各评一次；评价独立保存，不再加信用。信用、评分和完成次数分别计算。” |
| 02:55–03:00 | 展示双方评价及已评提示 | “记录保存在本浏览器；这不是共享数据库，手机兼容范围以验收记录为准。” |

可从“我的任务→我接的”重新找到阿晴参与的任务；详情的返回入口会回到原列表。列表较长时使用任务标题搜索，避免误点原有同类样例。

## 结束后核验与恢复

- 刷新同一详情，仍为已完成，双方评价各一条，阿晴仍为 82；个人页该任务只显示一条实际 +2。
- 关闭演示标签，再从同一浏览器重开详情链接；本地记录可恢复。其他浏览器或手机看到的是自己的独立记录。
- 再次演示前按准备步骤重置。普通刷新不会移动样例截止时间；已接任务超时也不会自动完成或扣分。
- 下载种子失败时用“重试加载”；损坏记录仅在确认后重置。临时会话提示出现时，不承诺刷新后保留修改。

## 本轮实际走查

2026-10-19，桌面内置浏览器以 localhost 独立站点记录开始，新任务“演示走查：顺路帮取小包裹”从首次说明到双向互评工具操作共 **131 秒**；包括观测，不包括旁白及重置准备。确认前 80，确认后 82，互评后不变；双方评分 5/4 星，刷新和关闭标签后按详情重开均保留结果。控制台 error/warn 为空。

该结果证明脚本的操作路径可走通，不是手机人工演示计时，也不证明真实 4G 三秒首屏目标。证据：artifacts/task-1-11-1-12/walk-timing.json、candidate-credit.txt、candidate-both-reviews.txt、candidate-refresh.txt、candidate-reopen.txt 和相应截图。
