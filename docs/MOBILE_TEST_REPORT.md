## 每端必须实际操作

使用手机自带浏览器打开正式入口即可，不要求安装App或启用USB调试。每台手机独立初始化、独立保存数据；一个完整双方流程须在同一手机上切换演示身份完成。

1. 记录设备/系统/浏览器/网络和页面版本，首次进入后确认演示说明；竖屏、横屏分别查看大厅、我的任务、详情和个人页。
2. 在“我的”确认重置。u001 发布虚构任务，检查空白标题、非法金额、过去截止时间的错误与输入保留；填写最后一个字段时观察软键盘遮挡、按钮可达性和键盘收起后的底栏恢复。
3. 切u002从大厅接单，经“我的任务→我接的”开始/交付；切u001确认完成，检查信用仅+2；重复点击、刷新、关闭重开、详情直达和返回均要实测。
4. 双方各评一次，分别查看评分与信用；输入含HTML的评论应原样显示，不能重复评，信用不增加。再验证低信用、自接、过期、取消、退出、异议和空结果。
5. 实测200%缩放或系统字体放大、刘海和底部手势区域、Android系统返回/iPhone返回手势；不将缩放后的截屏宽度作为唯一通过依据。
6. 切手机蜂窝网络并在未登录浏览器打开；记录首屏可操作耗时。加载后断网测试已有会话操作，首次离线按实际表现记录。损坏/禁用存储难以在手机复现时保留待验证，不能照抄桌面结果。
7. 每端至少保存一张带页面上下文的截图，优先最后字段+键盘和完成确认+信用；问题按复现步骤、预期/实际、严重程度、修复提交、复测记录归档。
