# 黄色强调色方案（待采用）

日期：2026-10-21（北京时间）。用户 task 2-1 要求仅制定方案，本轮未把下列黄色应用到页面或现有颜色变量。

## 参考色与依据

核对[美团官网](https://www.meituan.com/)及其当日加载的[官方样式文件](https://s3plus.meituan.net/static-prod01/com.sankuai.fspfecap.officeweb-files/_next/static/css/64da42ef41906699.css)，其中 `--adm-color-primary:#ffd100`，且多处背景使用 `rgb(255 209 0)`，本方案据此取 **#FFD100** 作为美团黄色参考。该值为官网实际用色，不将其表述为适用于美团所有产品的唯一品牌规范。

当前项目主绿为 #17664C，淡绿为 #EAF2E6，底色为 #F4F7F2。参考黄 HSL 约为 49.2° / 100% / 50%，直接大面积使用会比现有界面鲜艳。因此保留约 49° 的黄色色相，降低饱和度、提高明度，延续现有浅色、柔和的视觉风格；黄色与绿色使用不同色相，但保持协调的明度与饱和度层次。

## 建议颜色

| 用途 | 十六进制 | 使用方式 |
| --- | --- | --- |
| 美团黄色参考 | #FFD100 | 取色依据，不直接铺满页面 |
| 柔和重点黄 | #E5D9A5 | 重点按钮、酬谢金额底色、少量重要标记 |
| 浅黄色背景 | #F2F0E6 | 选中项、重点信息块、轻量提示的背景 |
| 按下/悬停黄 | #D6C98F | 重点黄色按钮的交互状态 |
| 黄色系文字 | #6B5F24 | 浅黄色上的文字、强调标签文字 |
| 保留主绿 | #17664C | 标题、普通链接、成功状态、品牌识别 |
| 保留正文色 | #19332D | 正文、黄色按钮上的深色文字 |
| 保留页面底色 | #F4F7F2 | 页面大面积背景 |

浅黄 #F2F0E6 的 HSL 约为 50° / 31.6% / 92.5%，与现有淡绿 #EAF2E6（100° / 31.6% / 92.5%）保持相同饱和度和明度。重点黄 #E5D9A5 约为 48.8° / 55.2% / 77.3%，在淡色层之上增加强调，但比原始美团黄柔和。

## 使用规则

- 保持白色卡片与浅绿底色，黄色用于少量重点，建议不超过可见面积的 10%。重点按钮用柔和黄加深色文字，其余操作保留绿色或中性色。
- 顶部标题与头像、底部导航先沿用绿色；采用方案后可将当前导航项背景改为浅黄、文字用深色。避免所有按钮、标签和图标同时变黄。
- 成功仍用绿，错误仍用红。“即将截止”保留文字辅助识别，不单靠黄底区分警告与普通重点。
- 黄色按钮不配白字：#19332D 在 #E5D9A5 上对比度约 9.53:1；#6B5F24 在 #F2F0E6 上约 5.59:1。比值由 sRGB 相对亮度计算；具体交互与字号在采用后再检查。

本轮实际页面继续使用现有绿色。配色方案待用户决定后单独实施。
